# MediaIsle

> 灵动岛风格的 Windows 媒体控制悬浮组件
> Dynamic Island style media controller for Windows

MediaIsle 是一枚悬浮于屏幕顶部中央的"灵动岛"——它实时显示系统中正在播放的音乐，悬停展开即为完整的媒体控制面板：进度、音量、歌词、收藏、多音源切换，一切触手可及。

## 特性

- **灵动岛多形态**：迷你 / 紧凑 / 音量 / 换歌通知 / 展开面板 / 收藏列表，随场景平滑变形
- **全局媒体控制**：基于 Windows SMTC，支持 Spotify、汽水音乐、浏览器等任意接入系统媒体的播放器
- **多音源切换**：多个播放器同时在线时，一键切换控制目标
- **歌词多源竞速**：
  - 汽水音乐 · 本地缓存（读取汽水客户端缓存，逐字歌词 + 中文翻译）
  - 网易云 / QQ音乐 / 酷狗 三源并发，支持竞速 / 质量择优 / 单源策略
  - 歌词精确匹配：繁简归一化 + 标题/歌手相似度校验，拒绝同名词曲误配
- **双语字幕**：原文在上、译文在下，岛体歌词列与桌面歌词均为双层结构
- **桌面歌词**：屏幕底部常驻显示当前句
- **听歌统计**：每日 / 近 14 天 / Top 8 曲目图表，纯本地记录
- **收藏列表**：一键收藏正在播放的歌曲
- **自动更新**：打包版启动后自动比对 GitHub Release 的构建日期，发现新版本可在设置中一键更新（源代码运行时不检查）
- **细节体验**：系统音量联动胶囊、全屏自动隐藏、毛玻璃模式、开机自启、进度拖动 seek、点歌词跳转

## 系统要求

- Windows 10 / 11
- [Node.js](https://nodejs.org/) ≥ 18（运行时由 Electron 渲染，PowerShell 5.1 系统内置无需安装）

## 运行

```bash
git clone https://github.com/Enderman939/MediaIsle.git
cd mediaisle
npm install
npm start
```

启动后 MediaIsle 常驻屏幕顶部，托盘图标提供显示/隐藏、设置与退出入口。

## 工作原理

```
┌─────────────┐  JSON/stdout   ┌──────────────┐   WinRT    ┌────────────────┐
│  Electron   │◄──────────────►│  bridge.ps1  │◄──────────►│  SMTC 媒体会话  │
│  主进程+UI  │   命令文件/轮询 │ (PowerShell) │  Core Audio│  系统音量/全屏  │
└─────────────┘                └──────────────┘            └────────────────┘
```

- **bridge.ps1**：PowerShell 桥接进程，通过 Windows Runtime 读取系统媒体会话（SMTC）与 Core Audio 主音量，并以命令文件接收控制指令（播放/暂停/seek/切换音源…），含 UTF-8→GBK 元数据乱码自动修复
- **歌词源**：汽水音乐读取其客户端本地 LMDB 缓存（`LunaCacheV2`，逐字歌词+翻译），其余走公开歌词接口
- **自动更新**：打包时将编译日期写入 `build-info.json`；应用启动后经系统代理拉取 Release 内的 `latest.json` 比对日期，更新通过临时目录解压 + 批处理换文件后自动重启
- **隐私**：配置、统计数据全部保存在本地 `%APPDATA%\MediaIsle`，不上传任何数据
